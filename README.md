## Project Goal

This is a relatable entertaining thriller game for people to play during their freetime.

## MVP Scope

2D video game where you have to escape a dining hall and find your phone to escape before the scanner attendant catches you.

## Future Plans

Fully developed map
Fully implemented art assets
Enemy AI with complex pathfinding
Publish game on itch.io

## Tech Stack

C# and Unity
